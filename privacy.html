개인정보처리방침

시행일 2026년 11월 7일

Pocket Index(이하 ‘서비스’)는 이용자의 개인정보를 소중히 여기고, 「개인정보 보호법」을 지켜요. 이 방침은 서비스가 어떤 정보를 왜 모으고, 어떻게 보관하고 지우는지 알려드려요.

1. 수집하는 개인정보

로그인하지 않아도 서비스를 이용할 수 있어요. 이때 담은 하트는 이용자 기기(브라우저)에만 저장되고, 서비스로 보내지 않아요.

로그인(소셜 로그인)을 하면 아래 정보를 받아요.

로그인 방법필수선택
카카오카카오계정(이메일), 카카오 회원번호없음

서비스를 이용하면서 만들어지는 정보도 저장해요: 하트를 누른 브랜드 목록, 고정·분류 설정, 로그인 기록(접속 일시).

비밀번호는 받지 않아요. 로그인 확인은 카카오가 직접 해요.

2. 이용 목적

  • 회원 식별과 로그인 유지
  • 하트 목록을 계정에 저장해 여러 기기에서 볼 수 있도록 제공
  • 문의 답변, 서비스 변경·중요 공지 안내

광고·마케팅 목적으로 쓰거나 다른 곳에 팔지 않아요.

3. 보관 기간과 파기

  • 회원 탈퇴 전까지 보관하고, 탈퇴하면 계정 정보와 하트 목록을 바로 지워요.
  • 법령에서 따로 보관하라고 정한 정보가 있으면 그 기간 동안만 보관해요.
  • 지운 정보는 다시 살릴 수 없는 방법으로 삭제해요.

4. 처리 위탁과 국외 이전

서비스 운영을 위해 아래 업체에 정보 처리를 맡기고 있어요. 회원 계정과 하트 목록은 대한민국(서울) 서버에 저장돼요. 웹사이트 호스팅 업체의 서버는 미국에 있어서, 사이트 접속 기록은 국외에서 처리돼요.

업체맡긴 일이전 국가·방법보관 기간
Supabase Inc.회원 계정·하트 목록 저장, 로그인 처리대한민국(서울, AWS 서울 리전) / 로그인·저장할 때 네트워크로 전송회원 탈퇴 시까지
GitHub Inc.웹사이트 호스팅(접속 기록 처리)미국 / 접속할 때 네트워크로 전송해당 업체 정책에 따름

Supabase Inc.는 미국 회사로, 서비스 관리를 위해 저장된 정보에 접근할 수 있어요. 이를 원하지 않으면 로그인하지 않고 이용하거나 회원 탈퇴를 할 수 있어요. 이 경우 계정 저장 기능을 쓸 수 없어요.

5. 제3자 제공

이용자 동의 없이 개인정보를 제3자에게 제공하지 않아요. 단, 법령에 따라 요청받은 경우는 예외예요.

6. 이용자의 권리

  • 언제든 내 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있어요.
  • 회원 탈퇴: 하트 탭 아래 ‘탈퇴’ 버튼을 누르면 바로 처리돼요.
  • 카카오 연결 끊기: 카카오톡 → 설정 → 카카오계정 → 연결된 서비스 관리에서 할 수 있어요.
  • 만 14세 미만은 회원 가입을 할 수 없어요.

7. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화해요.
  • 저장된 데이터는 암호화된 상태로 보관돼요.
  • 회원은 자기 데이터만 읽고 쓸 수 있도록 접근 권한을 제한해요.
  • 관리 계정은 2단계 인증으로 보호해요.

8. 쿠키와 브라우저 저장소

로그인 상태와 하트 목록을 기억하기 위해 브라우저 저장소(localStorage)를 써요. 광고·추적용 쿠키는 쓰지 않아요. 브라우저 설정에서 사이트 데이터를 지우면 저장된 내용도 지워져요.
